# I AM HERE, MI REINA — Interactive Story

An interactive, romantic web experience built with pure HTML5, CSS3, and Vanilla JavaScript. Designed to bring comfort, safety, and warmth during heavy days.

---

## 🚀 How to Deploy Directly to GitHub Pages

1. **Create a GitHub Repository:**
   - Go to [GitHub](https://github.com) and click **New Repository**.
   - Name your repository (e.g., `for-mi-reina`).
   - Keep it **Public** (required for free GitHub Pages).

2. **Upload Project Files:**
   - Upload the following 4 files directly into the root folder of the repository:
     - `index.html`
     - `style.css`
     - `script.js`
     - `README.md`

3. **Enable GitHub Pages:**
   - Go to your repository **Settings** tab.
   - On the left sidebar, click on **Pages**.
   - Under **Build and deployment** -> **Branch**:
     - Select `main` (or `master`).
     - Select `/ (root)` folder.
     - Click **Save**.

4. **Access Your Live Website:**
   - Wait 1–2 minutes for deployment.
   - GitHub will provide your live URL: `https://<your-username>.github.io/<repository-name>/`

## ✨ Key Features
- **Zero Dependencies:** No npm, Node.js, build step, or external libraries required.
- **Mobile-First & Fully Responsive:** Optimized for mobile phones with large touch targets and smooth rendering.
- **CSS Vector Animations:** Lightweight SVG characters with smooth breathing, walking, and hugging animations.
- **Accessibility:** Supports `prefers-reduced-motion` and clear typographic hierarchy.
